# 2026-09-10 — Loop iteration 2: the missing machiya row, and the slab at the head of the stairs

Base revision: main at df73b09 (iteration 1 integrated). Work entry: `docs/work/1_realism-and-content/plan.md`, iteration 2.

Cell distance 0.0768 → **0.0748**, SSIM 0.4559 → **0.4753**. Thresholds tightened 0.0783 → 0.0763 and 0.4509 → 0.4703, achieved minus the repo's recorded margins of 0.0015 and 0.005. Draw calls in the shot 317 → 326, triangles 594733 → 621440.

**Read every SSIM delta below 0.0054 with suspicion, not 0.0010.** Iteration 1's noise floor was measured across machines on byte-identical code. This session measured a bigger one *inside* one machine: `stackedStones` draws from a module-level PRNG, and simply moving one caller past two others — laying the same stones from a different point in the same stream — is worth **0.0004 of cell distance and 0.0054 of SSIM**, five times iteration 1's figure. Any change that adds or removes a random draw before a wall, a roof or a slab set in the photo view carries that much noise with it, and the only way to read a delta smaller than that is to hold the draws fixed, which is what `src/walls.js` now does explicitly.
